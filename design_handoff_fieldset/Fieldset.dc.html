Case study · Interaction design + build

The hardest control in B2B SaaS,
with the edge cases nobody demos.

Fieldset is a working query builder and data table over 5,000 fake companies — no backend, everything in the browser. Nested AND/OR groups, saved views, live match counts, virtualized rows, and the messy states real products get wrong.

Designed & built as a portfolio experiment. Everything below is interactive.

TRY 01
Selection that survives a filter change
Select a few rows, hit “Select all matching”, then tighten a condition. Fieldset asks what you meant instead of guessing.
TRY 02
A saved view pointing at a deleted field
Open the “EMEA legacy” view. The dead condition is flagged and ignored — the view still works instead of erroring.
TRY 03
50 on screen vs. all 5,000 matching
The header checkbox selects what you can see; the action bar offers the full matching set. Two different promises, kept separate.
TRY 04
50,000 rows, still smooth
Flip the demo toggle to 50k. Virtualized rows, multi-column sort (shift-click headers), resize and drag-reorder columns — no pagination.
